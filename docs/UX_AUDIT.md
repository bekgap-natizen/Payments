# Упрощение ежедневной работы (0.4.1 preview)

Загрузка ведомости → автоматический расчёт и предварительный выбор платежей → корректировка при необходимости → единое подтверждение и выгрузка Excel. Первый запуск требует включить действующих поставщиков и задать отсрочки.

- Общий долг включает все организации и поставщиков; наступивший срок рассчитывается для включённых в работу.
- Автогалочки — черновики. Ручные суммы, пустые черновики и оплаченные планы сохраняются.
- Расхождения, нераспределённый долг, устаревшие планы и поступления позже даты среза исключаются из массового подтверждения.
- Фильтр не ограничивает общий платёжный реестр; диалог явно подтверждает все выбранные организации.
- Excel: датированный компактный лист (одна строка на поставщика, итоги по организациям), общий долг, документы с суммами к оплате, сверка.
- Порядок организаций и поставщиков не изменён, накладные показываются от старых к новым. Таблица остаётся таблицей при узком экране, с собственной горизонтальной прокруткой.

Ограничения: распределение долга по документам остаётся расчётным, до получения регистра зачётов 1С. Не банковская система. Не добавлять реальные финансовые данные в публичный репозиторий.

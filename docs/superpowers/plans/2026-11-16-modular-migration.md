# План переноса Payments в GitHub

1. Взять проверенный локальный MVP 0.4 как базу; реальные XLSX исключить из репозитория.
2. Разделить общий исходник на `core/finance`, `one-c-parser`, `balances`, `xlsx-import`, `export/xlsx`, `ui/shell`, `ui/templates`, `ui/controller`, стили.
3. Восстановить загрузку через восемь независимых скриптов `defer`, оставить запуск без npm.
4. Добавить README, контракт 1С, схему слоёв и требования безопасности.
5. Прогнать unit-тесты, тесты на реальной ведомости локально и браузерный smoke-test.
6. В GitHub запушить отдельную ветку и открыть Draft PR для итогового просмотра и сверки.

## Бэклог после переноса

- Стабильный ID организации/поставщика вместо названий.
- Привязка оплат к входящим документам по регистру 1С.
- Серверный audit log, роли, RLS, backup, контроль конкурирующих утверждений.
- Рефакторинг `ui/templates.js` на пять независимых файлов представления при расширении UI.

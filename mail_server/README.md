VOLMAX Payments Mail Server — Windows Portable
================================================

КОМПЛЕКТ
- Запустить сервер.bat
- python/ — официальный встроенный Python (без установки)
- server/server.py — локальный почтовый модуль

ПЕРВЫЙ ЗАПУСК
1. Распакуйте весь ZIP в отдельную папку на Windows.
2. Запустите «Запустить сервер.bat».
3. Откроется http://127.0.0.1:8765/ — локальная страница настройки.
4. Введите почту Яндекс, с которой будут отправляться письма, и ПАРОЛЬ ПРИЛОЖЕНИЯ
   (не основной пароль аккаунта).
5. Нажмите «Проверить Яндекс и сохранить».
6. Не закрывайте окно сервера при работе с AppBox.
7. Откройте AppBox → Payments → «Подтвердить и отправить».
   При первом соединении введите шестизначный код из окна локального сервера.
   Если браузер запрашивает доступ к локальной сети — разрешите для AppBox.

ПОВТОРНЫЙ ЗАПУСК
- Достаточно запустить BAT.
- Логин и пароль приложения хранятся для текущей учётной записи Windows
  в Диспетчере учётных данных Windows; повторный ввод не нужен.
- Код подключения AppBox после перезапуска сервера запрашивается повторно.
- Сменить или удалить почтовые данные можно в локальном окне сервера.

БЕЗОПАСНОСТЬ
- Сервер слушает только 127.0.0.1:8765, а не внешнюю сеть.
- Разрешён единственный внешний origin: https://volmax.duckdns.org.
- Вся отправка происходит через SSL/TLS на smtp.yandex.ru:465.
- Реестр хранится в браузере AppBox; при отправке копия XLSX передаётся локальному модулю.
- История SMTP-попыток: %LOCALAPPDATA%\VOLMAX\PaymentsMail\sent.sqlite3.
- SMTP «accepted» означает приём письма сервером Яндекса, но не гарантирует доставку.
- Повтор одинакового письма требует отдельного явного подтверждения.
- Не публикуйте пароль приложения и корпоративные финансовые отчёты в GitHub.
- Перенос папки на другую учётную запись Windows требует повторной настройки почты.
- Антивирус, корпоративные политики и браузерные ограничения могут мешать localhost:
  работоспособность внутри установленного AppBox нужно проверить отдельно.

Для SMTP требуется почта, поддерживающая вход по пароль приложения Яндекса.

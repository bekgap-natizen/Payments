VOLMAX Payments Mail Server — Windows Portable
================================================

КОМПЛЕКТ
- Запустить сервер.bat
- python/ — официальный встроенный Python (без установки)
- server/server.py — локальный почтовый модуль

ПЕРВЫЙ ЗАПУСК
1. Распакуйте весь ZIP в отдельную папку на Windows.
2. Запустите «Запустить сервер.bat».
3. Откроется http://127.0.0.1:8765/ — локальная страница настройки.
4. Введите почту Яндекс, с которой будут отправляться письма, и ПАРОЛЬ ПРИЛОЖЕНИЯ
   (не основной пароль аккаунта).
5. Нажмите «Проверить Яндекс и сохранить».
6. Если Payments открыт с диска или встроен в AppBox с Origin: null, нажмите
   «Разрешить AppBox / локальный HTML» в окне сервера. Разрешение сохраняется до его отключения.
   Не закрывайте окно сервера при работе с AppBox.
7. Нажмите «Включить запуск по кнопке Payments» в локальном окне. Это регистрирует
   протокол volmax-payments://start для текущего пользователя Windows. Права администратора не нужны.
8. Откройте AppBox → Payments → «Подтвердить и отправить».
   При первом соединении введите шестизначный код из окна локального сервера.
   При необходимости нажмите «Получить код подключения».
   Если браузер запрашивает доступ к локальной сети — разрешите для AppBox.

ПОВТОРНЫЙ ЗАПУСК
- В режиме запуска по кнопке Payments проверяет доступность сервера, при необходимости
  вызывает зарегистрированный протокол и ожидает ответа до 18 секунд. Браузер может
  запросить разрешение на запуск внешнего приложения. После запуска сервер остаётся работать.
- Резервный режим: «Включить автозапуск Windows» запускает сервер при входе в Windows.
  При необходимости откройте http://127.0.0.1:8765/ для настройки.
  Для ручного запуска достаточно BAT. Храните папку сервера в постоянном месте.
  При переносе или обновлении папки зарегистрируйте запуск по кнопке заново.
  Для теста холодного запуска закройте старый сервер (или завершите его процесс Python,
  относящийся к Mail Server), затем нажмите синюю кнопку Payments.
- Логин и пароль приложения хранятся для текущей учётной записи Windows
  в Диспетчере учётных данных Windows; повторный ввод не нужен.
- Привязка сохраняется после перезапуска сервера и браузера, если браузер разрешает локальное хранение.
- Если хранилище AppBox запрещено, при новом сеансе может потребоваться код.
- В обычном режиме нажмите «Подтвердить и отправить», затем «Отправить» в единственном окне.
- Для отзыва доступа нажмите «Сбросить все привязки Payments».
- Сменить или удалить почтовые данные можно в локальном окне сервера.

БЕЗОПАСНОСТЬ
- Протокол запуска передаёт только фиксированную команду старта, без документов, токенов и паролей.
- Сервер слушает только 127.0.0.1:8765, а не внешнюю сеть.
- Разрешён origin https://volmax.duckdns.org; для встроенных страниц и файлов
  Origin: null допускается только после явного разрешения в локальном окне сервера.
  Для отправки в обоих случаях нужен токен, привязанный к origin, полученный по одноразовому коду.
  Режим совместимости сохраняется до отключения. Другие сайты не разрешены.
  Сервер хранит только хеши токенов; токен сохраняется в браузере. Смена почтового аккаунта отзывает привязки.
- Вся отправка происходит через SSL/TLS на smtp.yandex.ru:465.
- Реестр хранится в браузере AppBox; при отправке копия XLSX передаётся локальному модулю.
- История SMTP-попыток: %LOCALAPPDATA%\VOLMAX\PaymentsMail\sent.sqlite3.
- SMTP «accepted» означает приём письма сервером Яндекса, но не гарантирует доставку.
- Повтор одинакового письма требует отдельного явного подтверждения.
- Не публикуйте пароль приложения и корпоративные финансовые отчёты в GitHub.
- Перенос папки на другую учётную запись Windows требует повторной настройки почты.
- Антивирус, корпоративные политики и браузерные ограничения могут мешать localhost:
  работоспособность внутри установленного AppBox нужно проверить отдельно.

Для SMTP требуется почта, поддерживающая вход по пароль приложения Яндекса.

# ВОЛМАКС Платежи 0.7.0 — единый Windows-сервер (пилот)

Рабочая версия AppBox 0.6.13 не заменяется автоматически. Это отдельный пилот для проверки с условными данными.

## Установка
1. Распаковать Windows ZIP в постоянную папку. Закрыть старый процесс Mail Server, запустить BAT новой сборки. Не запускать два экземпляра.
2. Окно localhost:8765 сохраняет настройки, привязки, пароль приложения Яндекса (Windows Credential Manager). Проверить отправку на тестовой среде. При переносе папки повторно включить запуск по кнопке и автозапуск.
3. Для мобильного модуля требуется один постоянный HTTPS-адрес, который направляет запросы на 127.0.0.1:8780 на этом компьютере. Например существующий обратный прокси с TLS, или настроенный на данном компьютере туннель с постоянным доменом. НЕ публиковать порт 8765. Не публиковать временный открытый HTTP. Публичный адрес и доступ к маршрутизатору/домену пока не настроены; уточните у администратора. Не перенаправлять существующий адрес AppBox без проверки. Сам Windows ZIP не создаёт публичный домен/HTTPS автоматически.
4. В окне VOLMAX Server введите этот HTTPS-адрес и нажмите «Подключить мобильный модуль». Запускаются мобильный HTTP listener (только loopback:8780) и push worker. При следующем запуске настройки читаются автоматически.
5. Выберите роль, нажмите «Подключить устройство (QR)». QR-код одноразовый, действует 15 минут. Для бухгалтера откройте ссылку в браузере компьютера, для директоров — на телефонах. iPhone/iPad: Safari → «Поделиться» → «На экран Домой», откройте иконку и подключите устройство кодом; Android: Chrome → установить. Если Safari и установленное приложение не разделяют сессию, создайте новый QR/код и введите его в установленном приложении. Вход по коду сохраняется на 180 дней, до очистки данных браузера или отзыва. При потере телефона используйте отзыв подключений выбранной роли в локальном окне.
6. Разрешить уведомления внутри установленного приложения. iOS 16.4+; на некоторых устройствах ограничения браузера/ОС/сети могут препятствовать доставке. Финансовые суммы на экране блокировки — только по отдельному согласию.
7. Бухгалтер открывает в портале «Рабочее место бухгалтера» (тот же интерфейс и логика 0.6.13), загружает тестовую ведомость, настраивает поставщиков, отправляет реестр. Оба директора получают push. Первый директор, принявший решение, блокирует повторное решение; второй директор и бухгалтер получают уведомление. Отправка утверждённого реестра по почте выполняется сервером через существующий SMTP-модуль, без повторной настройки почты.

## Ограничения
- Это отдельное рабочее пространство HTTPS. Локальные черновики/настройки из AppBox 0.6.13 не мигрируют автоматически. Для первого теста повторно загрузить вымышленный файл 1С и настроить поставщиков. Старая версия остаётся независимой; не используйте оба пути для одного реального платежа.
- Обзор строится по последнему отправленному снимку действующих поставщиков, не является живым подключением к 1С. Дата снимка явно указана.
- Компьютер должен быть включён, без сна, с работающим сервером и интернетом. Для автоматического старта включить соответствующий пункт в окне.
- Сервер хранит данные локально в %LOCALAPPDATA%\VOLMAX\PaymentsMail\Mobile. Настроить резервное копирование через SQLite backup API, проверить отзыв доступа, публичный HTTPS, реальные iOS/Android, SMTP и работу внутри AppBox до финансовых данных. Не размещать базу, ключи, реальные отчёты или пароли в GitHub.
- Автотесты не подтверждают доступность по интернету, доставку реальных push/писем или безопасность конкретной сетевой конфигурации.
- Сервис не переводит деньги в банк.
